# ⛓️ بوت السجن (Jail Bot) 🚔

بوت ديسكورد متكامل لإدارة نظام السجن في السيرفرات.  
يدعم: سجن أعضاء، سجن جماعي، فك سجن تلقائي بانتهاء المدة، لوحة تحكم كاملة، صلاحيات مخصصة.

---

## 🚀 النشر على منصة مجانية (Koyeb) — الأفضل 🏆

**Koyeb** منصة استضافة مجانية بالكامل (بدون بطاقة ائتمان). تدوم للأبد.

### خطوات النشر (مرة واحدة فقط):

1. **سجل حساب** في [koyeb.com](https://www.koyeb.com) (يكفي بريد إلكتروني)
2. **اربط حساب GitHub** الخاص بك مع Koyeb
3. **افتح** [تطبيق Discord Developer Portal](https://discord.com/developers/applications)
   - اذهب إلى البوت ← Bot → نسخ **Token**
4. **في Koyeb:**
   - اضغط **Create App** → **Deploy from Git (Dockerfile)**
   - اختر repo: `momen7alsmadi-droid/j3_discloud`
   - في **Environment Variables** أضف:
     - `TOKEN` ← `ضع_توكن_البوت_هنا`
   - اضغط **Deploy** 🚀

> البوت سيعمل 24/7 مجاناً ✅

## 🚀 البديل الثاني: Render (مجاني)

1. **سجل حساب** في [render.com](https://render.com) (اربط GitHub)
2. اضغط **New +** → **Web Service** → اختر repo `j3_discloud`
3. الإعدادات:
   - **Runtime**: `Docker`
   - **Branch**: `main`
4. أضف متغير البيئة: `TOKEN` ← قيمة التوكن
5. اضغط **Create Web Service** ✅

> ⚠️ في Render الفئة المجانية، البوت قد يتوقف بعد 15 دقيقة من عدم النشاط → استخدم **Koyeb** بدلاً منه.

## 🚀 النشر على DisCloud (إذا كانت الخدمة متاحة)

```yaml
# ملف discloud.config موجود مسبقاً
ID=1528694752336416768
TYPE=bot
MAIN=bot.py
RAM=100
AUTORESTART=true
VERSION=latest
```

> **ملاحظة**: DisCloud أغلقت الخدمة المجانية حالياً.

> ⚠️ **تنبيه أمني مهم في جميع المنصات**:  
> لا تضع التوكن داخل `config.json` — استخدم متغير البيئة `TOKEN`.

## ⚙️ الإعداد داخل السيرفر

بعد تشغيل البوت، استخدم الأمر `/settings` في السيرفر لفتح لوحة التحكم:

1. 🚪 **روم السجن** — اختر الروم الذي سيرى المسجونين الرسائل فيه
2. ⛓️ **رتبة السجن** — اختر الرتبة التي تضاف للمسجونين
3. 📜 **روم اللوق** — اختر الروم لتسجيل جميع العمليات
4. 🔄 **مزامنة الرومات** — اضغط لتطبيق الإخفاء على جميع القنوات

---

## 📋 الأوامر

| الأمر | الوصف |
|---|---|
| `/jail <user> <reason> [duration]` | سجن عضو واحد |
| `/jailmany <users> <reason> [duration]` | سجن جماعي (ضع منشنات أو آيديات) |
| `/unjail <user>` | فك سجن عضو |
| `/jailtime <user> <duration>` | تعديل مدة السجن |
| `/jailinfo <user>` | عرض تفاصيل سجن عضو |
| `/jaillist` | عرض كل المسجونين |
| `/settings` | لوحة التحكم (للمالك والمطور فقط) |

### صيغ المدة (`duration`):

| الوحدة | المعنى | مثال |
|---|---|---|
| `s` | ثواني | `30s` |
| `m` | دقائق | `10m` |
| `h` | ساعات | `1h` |
| `d` | أيام | `2d` |
| `w` | أسابيع | `1w` |
| `mo` | أشهر (30 يوم) | `3mo` |

اترك `duration` فارغاً للسجن المؤبد.
