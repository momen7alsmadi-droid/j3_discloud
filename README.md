# ⛓️ بوت السجن (Jail Bot) 🚔

بوت ديسكورد متكامل لإدارة نظام السجن في السيرفرات.  
يدعم: سجن أعضاء، سجن جماعي، فك سجن تلقائي بانتهاء المدة، لوحة تحكم كاملة، صلاحيات مخصصة.

---

## 🚀 النشر على DisCloud (مجاني)

هذا المشروع معد مسبقاً للنشر على **DisCloud** (منصة استضافة مجانية لبوتات ديسكورد).

### الخطوات:

1. **سجل حساب** في [discloud.com](https://discloud.com)
2. **اربط حساب ديسكورد** الخاص بك
3. **اضغط على "Upload Bot"** وارفع ملف `j3_discloud.zip` (أو كل ملفات المشروع)
4. **من لوحة التحكم** اذهب إلى إعدادات البوت و **ضع التوكن في متغير البيئة**:
   - اسم المتغير: `TOKEN`
   - القيمة: `ضع_توكن_البوت_هنا` (انسخه من [Discord Developer Portal](https://discord.com/developers/appplications))

> ⚠️ **تنبيه أمني مهم**: لا تضع التوكن داخل `config.json` عند رفع المشروع على GitHub.  
> استخدم متغير البيئة `TOKEN` في DisCloud بدلاً من ذلك.

### ملفات الإستضافة المرفقة:

| الملف | الوظيفة |
|---|---|
| `discloud.config` | إعدادات DisCloud (نوع البوت، الذاكرة، إلخ) |
| `requirements.txt` | المكتبات المطلوبة (`discord.py==2.7.1`) |
| `start.sh` | سكريبت التشغيل |
| `bot.py` | كود البوت الرئيسي |

## 💻 التثبيت المحلي (Termux / PC)

```bash
# ثبّت المكتبات
pip install -U discord.py

# انسخ ملف الإعدادات
cp config.example.json config.json
# ثم افتح config.json وضع التوكن الحقيقي
```

### التشغيل:

```bash
python bot.py
```

أو:

```bash
bash start.sh
```

## ⚙️ الإعداد داخل السيرفر

بعد تشغيل البوت، استخدم الأمر `/settings` في السيرفر لفتح لوحة التحكم:

1. 🚪 **روم السجن** — اختر الروم الذي سيرى المسجونين الرسائل فيه
2. ⛓️ **رتبة السجن** — اختر الرتبة التي تضاف للمسجونين
3. 📜 **روم اللوق** — اختر الروم لتسجيل جميع العمليات
4. 🔄 **مزامنة الرومات** — اضغط لتطبيق الإخفاء على جميع القنوات

---

## 📋 الأوامر

| الأمر | الوصف |
|---|---|
| `/jail <user> <reason> [duration]` | سجن عضو واحد |
| `/jailmany <users> <reason> [duration]` | سجن جماعي (ضع منشنات أو آيديات) |
| `/unjail <user>` | فك سجن عضو |
| `/jailtime <user> <duration>` | تعديل مدة السجن |
| `/jailinfo <user>` | عرض تفاصيل سجن عضو |
| `/jaillist` | عرض كل المسجونين |
| `/settings` | لوحة التحكم (للمالك والمطور فقط) |

### صيغ المدة (`duration`):

| الوحدة | المعنى | مثال |
|---|---|---|
| `s` | ثواني | `30s` |
| `m` | دقائق | `10m` |
| `h` | ساعات | `1h` |
| `d` | أيام | `2d` |
| `w` | أسابيع | `1w` |
| `mo` | أشهر (30 يوم) | `3mo` |

اترك `duration` فارغاً للسجن المؤبد.

## 🔒 الأمان
